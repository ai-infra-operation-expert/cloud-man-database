## 核心观点(1 段话)

> **AI Native 团队 = 把全团队所有 work(研发/工单/值班/PDSA/集测/PD/PM)都当成 project,全部数字化,入 context graph,然后让 AI + 人协作,飞轮越转越快。**
>
> **Process 是 context 的输入管道,People 是飞轮的驱动力,Measure 是飞轮的转速表,Context 是飞轮的本体。**

## 4 维度框架

1. **Context** — 知识资产怎么积累、流动、复用
2. **Process** — 全团队所有 work 怎么数字化,入 context
3. **People** — 团队结构、招聘、技能
4. **Measure** — 度量、激励、考核

## 12 个月路线图

- **0-3 月**:Process 数字化盘点 + Context 资产化(工单试点)
- **3-6 月**:6 大 work stream 全面推开 + AI Copilot MVP
- **6-12 月**:全 work 接入 context graph + 团队结构转型
